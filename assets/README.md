# Assets

Everything in this folder is either downloaded from a recorded upstream or
generated by a script in `tool/`. Nothing here was made by hand, and nothing
here should be edited by hand — regenerate it instead, or the next person to run
a generator will silently overwrite the change.

| Group | Bytes | Files | Produced by |
|---|---:|---:|---|
| `fonts/` | 975,907 | 8 | `tool/fetch_fonts.py` → `tool/subset_fonts.py` |
| `images/` | 124,112 | 4 | `tool/generate_assets.py` |
| `icons/` | 17,380 | 4 | `tool/generate_assets.py` |
| `audio/` | 16,895 | 3 | `tool/generate_audio.py` |
| **Total** | **1,134,294** | **19** | **≈ 1.08 MB added to the APK** |

Dart references them through `lib/app/asset_constants.dart`, which is generated
from these directories by `tool/generate_asset_constants.py`. `pubspec.yaml`
declares the directories, not individual files, so the two cannot drift apart.
`test/platform/asset_manifest_test.dart` fails the build if they do.

## fonts/

Vendored, not fetched at runtime. `google_fonts` downloads faces over the
network on first use, and this app declares no `INTERNET` permission at all
(see `test/platform/offline_and_manifest_test.dart`) because a group has to be
able to play in a basement with no signal. A runtime loader would fall back to
the system face forever and nobody would notice.

| Family | Role | Notes |
|---|---|---|
| Bebas Neue | Latin display | Uppercase-only, strongly condensed |
| Cairo | Arabic display | Variable (`wght`); also the Latin display's Arabic fallback |
| IBM Plex Sans Arabic | Body, both scripts | 400 / 500 / 600 |
| IBM Plex Mono | Figures and timers | 400 / 500, tabular |

All four are SIL OFL 1.1. `OFL.txt` carries the licence and the per-family
copyright lines, and `main.dart` registers it with `LicenseRegistry` so it shows
up in the app's own licence page.

**Subsetting.** `tool/subset_fonts.py` trims each face to Latin + Arabic,
cutting 1,655,872 B to 971,032 B (−41.4%). Arabic is a joining script, so the
subsetter keeps the full OpenType feature set (`--layout-features='*'`) plus the
presentation-forms blocks and the joiner controls — dropping those produces a
font that renders every character and renders all of them disconnected.

This was verified, not assumed: the app was screenshotted before and after
subsetting and diffed. The only pixels that changed anywhere on screen were the
status-bar clock. Re-verify the same way if the ranges are ever edited.

### Changing the display face

The three Phase-1 candidates (Bebas Neue, Cinzel, Anton, each paired with an
Arabic partner) were compared on a device and **A · Interrogation** — Bebas Neue
over Cairo Black — was chosen. The losers were deleted so the APK does not carry
three unused display families.

To reopen that decision: `python tool/fetch_fonts.py --all` restores every
candidate, then edit `MafiaTypography.defaults` in
`lib/ui/theme/design_tokens.dart`.

## images/ and icons/

Generated by `tool/generate_assets.py`, which is deterministic — fixed random
seeds, so re-running it does not churn the repository.

The palette is **sampled from the art-direction reference** rather than chosen
by hand, so the generated surfaces and `design_tokens.dart` come from one source
instead of two that nearly agree. The reference is a painterly noir playing-card
set whose warm card (rust, oxblood, aged canvas) and cold card (charcoal,
gunmetal, bone) are the same artwork in two registers — which is exactly the
split the app needs. Home and Result get the warm register; night screens, the
pass screens and the card faces get the cold one.

The painterly quality comes from `_fbm()`, tileable fractal noise built in the
frequency domain. Broad mottling is baked into the large surfaces that need it;
`canvas_texture.webp` carries only the fine weave, because noise is close to
incompressible and a single sheet holding both cost 190 KB.

| File | Purpose |
|---|---|
| `card_back.webp` | The card back. **One file, used by all four roles.** |
| `card_face_base.webp` | The card face. Also one file for all four roles. |
| `canvas_texture.webp` | Tileable canvas weave, overlaid on every surface |
| `home_backdrop.webp` | Ambient backdrop, Home and Result only |
| `role_*.webp` | The four role emblems, white shapes carried in alpha |

### The zero-leakage constraint

Doc 05 rules 3 and 6 require the four role cards to be indistinguishable in
everything except the symbol. Two structural decisions enforce that:

1. **There is only one card back and one card face in the repository.** Not four
   that happen to match — one. A per-role surface cannot drift out of alignment
   if it does not exist. The manifest test asserts no `card_*` file other than
   these two ever appears.
2. **The four emblems ink the same fraction of the frame.** They are solved to a
   fixed 27.00% coverage target, and they hit it within 0.24%, against a budget
   of ±2%.

The emblems are matched by varying each symbol's *internal weight* — stroke
thickness, cutout size — inside a shared bounding box, not by scaling them. An
earlier version scaled them instead: it hit the ink budget just as precisely and
looked wrong, because matching a solid mask to a thin outlined magnifier by area
forces the mask to shrink and the magnifier to grow, and the set then reads as
four different sizes.

Ink parity is re-measured from the **shipped bytes** by
`test/platform/asset_manifest_test.dart`, not just printed by the generator. The
generator being correct when it ran says nothing about the files in the repo
today, and a lossy re-compression eating a thin stroke would not show up any
other way.

## audio/

Generated by `tool/generate_audio.py`. Doc 01 §8 lists six cues; the three here
are the functional ones and are pure synthesis:

| File | Doc 01 spec |
|---|---|
| `speaker_change.ogg` | Short neutral chime, < 1s |
| `timer_end.ogg` | Two ascending tones |
| `elimination_reveal.ogg` | Single deep drum hit |

The chime is built from a pitch, its octave and its twelfth, with no third
anywhere, so it carries no major/minor colour for the table to read into. The
drum is a downward pitch sweep rather than a bass note, which is what makes a
sine read as a struck skin.

### Not present, and deliberately so

The other three cues — `night_falls`, `mafia_wake`, `morning` — are spoken
Arabic narration. They need a voice actor and cannot be synthesised. No
placeholder is committed, because a silent file sitting in this folder looking
like a finished asset is worse than an obviously missing one.

### Not yet audible

`AudioDirector` currently records cues without playing them: the audio package
was removed because its native build hook cannot run from an SDK path containing
a space (see the note in `pubspec.yaml`). The on-table/in-hand gate it enforces
is real and tested regardless. These files are ready for the day playback
returns.

## No `lottie/`

Considered and skipped. The only motion that was a candidate for it is the
post-game achievement badge entrance, which is a staggered scale-and-fade that
Flutter does natively. Adding `lottie` would mean a new dependency, a JSON
runtime, and APK weight for an effect already covered — against an offline-first
size budget.

## No SVG

The role emblems are authored directly as measured alpha masks rather than as
SVG. Rendering SVG in Flutter needs the `flutter_svg` dependency, and the ink
parity above has to be *measured in pixels* to mean anything — which means
rasterising regardless. Going straight to raster removes a dependency and a
conversion step without losing anything: these emblems are only ever drawn at
one size.
