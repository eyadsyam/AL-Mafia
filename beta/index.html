This is a test build. It did not come from Google Play and it is signed with a private key, so Android will ask you about it during installation.

If you got it from anywhere other than this page, do not install it.

Download the app APK · about 39 MB · Android 8 and above

How to install

  1. Open this page on the phone itself and tap “Download the app”.
  2. Your browser will warn that this kind of file can harm your device — that warning appears for every .apk. Tap Download anyway.
  3. Open the file from the notification, or from your Downloads folder.
  4. The first time only, Android will say this browser is not allowed to install apps. Tap Settings, turn on Allow from this source, and come back.
  5. Tap Install. If Play Protect appears, tap Install anyway.

To remove it, uninstall it like any other app — long-press the icon, Uninstall. Nothing is left behind.

Rather not install anything?

There is a web build that plays in the browser: open it here. Online play works there too — the installed build is just faster, and works with no network at all.
