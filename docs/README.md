# docs

| Folder | What lives there |
|---|---|
| `PROGRESS.md` | The phase log. Read first after any `/clear`. |
| `specs/` | The binding specs: 01–05 design and zero-leakage, 09–16 engine and online, contracts. |
| `plans/` | Plans and briefs, built or still waiting (Big Update 1.1, Character Chapters, art requests). |
| `brand/` | Brand kit, asset plan, AI art brief. |
| `setup/` | One-time service setup: accounts, push, email, domain, web ads. |
| `reviews/` | Audits and reviews of finished work. |
| `release/` | Play release notes and policies. |
| `marketing/` | Marketing plans, posts, listing copy. |
| `store-v2/`, `ux/`, `cloud/` | Store art catalogue, UX audit, cloud prompts. |
| `archive/` | Old hand-offs between sessions and agents. History only. |

Outside `docs/`: `HANDOFF.md` (repo root) is the cold-start checkpoint;
`raw_assets/` holds source art, including prepared art not yet in the app
(`raw_assets/update11/` for Character Chapters); `release/<version>/` (local, not
in git) holds every shipped build with its symbols.
