WHAT TO BUILD
1. tool/night_matrix.dart: a deterministic generator (`dart run tool/night_matrix.dart`) that ENUMERATES night scenarios as a cartesian product over these axes (prune only impossible combinations; aim for several hundred cases, every axis value appearing with every other at least once — pairwise coverage minimum, full product where it stays under ~1500 cases):
   - table: 5, 7, 9, 12 seats with the standard Mafia counts the app deals (read the deal rule in the engine), with and without Silencer, Sniper, Elder, Detective;
   - Mafia votes: unanimous on each target kind (citizen, doctor, detective, elder, sniper, silencer-not-allowed), split 1-1, split 1-1-1, one Mafioso skips, all skip (quiet night when the bullet is available / spent / disabled);
   - Doctor: protects the victim, protects someone else, protects self (first time / second time), protects the same seat as last night (must be refused — assert the refusal path, do not resolve it), skips;
   - Silencer: silences a town seat, the victim, a seat the Sniper kills, nobody; inherits the kill when no Mafioso is alive;
   - Sniper: shoots a Mafioso, a Silencer, a town seat, the protected victim, nobody, with the bullet spent;
   - Detective: investigates each role (record the result it reveals);
   - tools that change the night if the engine models them offline (lock_door, half_door — check doc 17 for which side implements them; if offline does not, generate them only for the TS side with the rule as oracle);
   - second night (state carried: bullet spent, last protect) for the cases where history matters.
   For each case write the input exactly as night_vectors.json does, plus `expected` from the REAL Dart MatchEngine, plus `tiedSeats` when the Mafia (or protect) choice was a tie.
2. supabase/tests/night_matrix.test.mjs: replays every case through resolveNightCore. Non-tie cases: identical deaths / saved / saveTold / silenced. Tie cases: the TS victim is one of `tiedSeats` and every other field is consistent with that pick (recompute the expected outcome for the TS pick with the same rules). Cases marked knownDivergence are reported with test.skip and their reason, never silently passed.
3. test/engine/night_matrix_test.dart: the same cases against an independent RULE ORACLE written in the test from doc 17 (not by calling the resolver): e.g. a Mafia-team seat never dies to the Mafia kill; a protected victim lives and saveTold follows the settings; a locked seat is untouchable; a Sniper hit kills the Mafia-team target only, a miss kills target and Sniper; quiet night kills nobody; a silenced seat that dies is not reported silenced; deaths are sorted by seat; nobody already dead dies again. Assert the engine's outcome equals the oracle's for every case (ties: oracle gives the set).
   Run it with: flutter test --no-pub test/engine/night_matrix_test.dart
