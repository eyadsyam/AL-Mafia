An entry may cite several layers; counts at the end count each layer independently. Live `*_match.py` suites are executable against the hosted bot-account server; `live_local_*.test.mjs` are written but **not run on this machine** and are identified as `S-written` where used. Source-only behavior never counts as proof. Test labels after `::` are exact test names or distinctive assertion/scenario labels. A `D#` identifies a divergence described by doc 17; newer implementation/tests may supersede that historical description and are called out below.
