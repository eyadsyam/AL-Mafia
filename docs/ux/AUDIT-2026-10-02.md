# Mafia Master UI/UX audit — 2026-10-02

Release web build inspected in Chromium at 390×844 and 412×915. The offline path was played from first run through victory and all four analytics tabs. The online entry and create/join sheets were opened; the lobby and live table could not connect without a configured backend, so their widgets were reviewed in code. Rewards, missions and account sign-in were also reviewed in code because this local web build has no backend or Google identity provider. The screenshots in the temporary `scratchpad/ux/` directory are numbered by path through the app. The public Play build and its native ad surface were not available in this run.

Effort: S = one focused widget/copy edit, M = shared component or flow edit, L = cross-screen redesign.

## Design system cleanup

- Use `MafiaSpacing`, `MafiaTypography`, `MafiaColors`, `MafiaRadii` and `MafiaTiming` for all new UI values. Apply the shared 48dp target and 1.6 Arabic line-height through reusable action and section widgets.
- Unify primary/secondary buttons and sticky action bars across setup, result and sheets. The primary verb should name its actual effect: “ابدأ اللعبة”, “احفظ”, “سلم الموبايل”.
- Use a common bottom-sheet header, compact question row and inline loading/error state for secondary flows. Preserve the dark/gold Vault/Council/Missions art vocabulary without using decorative text as essential instructions.
- Keep night layouts, durations, brightness and spoken feedback identical across roles. The private confirmation detail must be absent before the pass control can be used.
