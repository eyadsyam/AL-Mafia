# Store identity migration — review gate blocked

No commit, deployment, release, web or APK build was performed. This is an
implementation for review, not a verified whole-app completion. Flutter's installed
cache is not writable and package source reads are denied in this session.

## Audit

The [source inventory](IDENTITY-INVENTORY-2026-10-08.md) scans all 190 UI Dart files
and records 88 screen/flow/sheet files. Rendered review is still outstanding.

- Home, setup, online entry/lobby, account, onboarding, help and postgame used the
  base Material buttons instead of the store's struck gold and enamel rim.
- Mode selection stacked large competing cards below a large illustration.
- Settings had its own gradient, badges, headings and separators. Help and
  onboarding used paper panels; setup, history, profile and stories had separate
  flat panel treatments.
- Story metadata had a separate pill treatment. Loading, empty and retry states
  were composed independently. Setup headers shrank long titles with FittedBox.
- The bot sheet had a non-scrolling column. Shared link rows had no explicit
  minimum height. These are addressed structurally; 360 px render checks remain
  blocked.
- Character portraits, progress seals, diagrams, public result art and story
  Ruqaa headings carry meaning rather than generic surface styling; retain them.
- Private match screens are intentionally a neutral subset of the identity.

## Shared API

Import `lib/ui/widgets/mafia_kit.dart`. The former economy/vault_kit.dart is a
compatibility export, not another implementation.

| API | Contract |
|---|---|
| MafiaPanel | Arbitrary bounded child, size, padding and margin; the exact VaultCard paint and engraving. |
| MafiaCard / VaultCard | Content panel; VaultCard retains store-only lit/tag options. |
| MafiaHeading / VaultHeading | Wrapping section heading, optional subtitle, leading and trailing content. |
| FilledButton + vaultGoldStyle | Native primary control, struck gold, disabled/pressed states. |
| OutlinedButton + vaultOutlineStyle | Native secondary control, gold rim on enamel. |
| TextButton | Native tertiary action using the existing themed 48 px target. |
| MafiaPill / ChoiceChip | Passive pill / native selectable pill under the public theme. |
| MafiaListRow | Wrapping heading and detail, optional adornments, minimum 48 px target. |
| MafiaEmpty | Localized title/message with an optional action supplied by the caller. |
| MafiaLoading / VaultSkeleton | Finite, static accessible loading skeleton. |
| MafiaError / VaultRetry | Localized failure with a retry action. |
| MafiaScaffold | Public theme, optional standard title/back/padding, native Scaffold slots. |
| MafiaPublicTheme | Scoped public controls, chips, dividers and app bar; text scale 1.0. |
| showMafiaSheet | Native secondary sheet with the same theme, radius and hairline. |

Existing RewardChip, VaultBar, VaultDivider, VaultPress, VaultGlint, ClaimedMark,
LampGlow and ScrollFadeEdge remain available from the same implementation. Arabic
tag/chip text no longer overrides the shared 1.6 line height with 1.2.

## Migration scope

Public scaffold/theme: home, mode, add players, group picker, roles, settings,
profile, help, how-to-play, scenario store, coin store, stories hub and story
flow, character dossiers, account route, first-run/video onboarding, online
entry/lobby, history, result, analytics and the two admin destinations.

Shared surface/heading changes: mode choices become one calm panel of rows;
settings cards/rows/headings and setup headers use the kit; role steppers,
group rows, save-group prompt, history records/empty state, account summary,
story cards/metadata/timeline/private blocks, help and onboarding cards use
shared primitives. Story title styling remains StoryTokens.ruqaa.

The bot sheet scrolls and uses shared headings. Bot setup, help, story player
count/accusation, account deletion, friends, casebook and store-item sheets use
the common sheet entry point. Existing button types and callbacks are retained.
No translation meaning, engine, ad placement or game transition was changed.

This does not claim every custom public decoration was removed. Portrait auras,
progress marks, artwork masks, attendance status, semantic warnings and store
merchandising retain their specialized treatment. Additional visual alignment
must be decided from renders, not assumed from compilation.

## Doc 05 decisions

1. The global MafiaTheme and AppBackdrop are unchanged. Gold is scoped to public
   destinations, never installed above the match navigator.
2. Distribution/reveal, handoff/hold, night action, voting, discussion,
   confrontation and morning screens retain their existing trees, palette,
   dimensions, timing, transitions, tap sequence and back policy. The online
   table/council/witness/private/scene/host moderation surfaces also remain
   unchanged. No role-dependent lit rim, tag, glint or animation is added.
3. Shared ScreenHeader is used by setup/help only. SettingsPanel's users are
   setup and room settings; this migration does not add settings to private
   turns. Existing SettingsLinkRow uses remain word/data controls.
4. Final result and analytics are public postgame destinations and receive
   button styling only; role/winner data and reveal rules are untouched.
5. Authored story blocks use identical static panel paint regardless of their
   contents; no role-dependent treatment or new timing/interaction is added.
6. No gameplay banner placement changes, `if (isOnline)` branches, or engine
   edits were introduced. Leakage and golden tests still require execution;
   there is no claim that they passed here.
